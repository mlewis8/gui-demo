# Python Ping-Pong

A simple two-player Ping-Pong game made with Python's built-in `turtle` graphics module.

## Run the game

1. Install Python 3.10 or newer. On Linux, ensure Tkinter is installed.
2. From this directory, run:

   ```bash
   python ping_pong.py
   ```

No third-party Python packages are required.

## Controls

| Player | Move up | Move down |
| --- | --- | --- |
| Left | `W` | `S` |
| Right | Up arrow | Down arrow |

- First player to 10 points wins.
- Press `R` to restart.
- Press `Esc` to quit.

Paddle hits change the ball's angle and gradually increase its speed.
